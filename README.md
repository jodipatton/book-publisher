# book-publisher

This repository previously hosted the VoiceAtelier fashion-design prototype
under `apps/fashion-creator/`. That app has been promoted to its own
repository — see [`jodipatton/fashion-creator`](https://github.com/jodipatton/fashion-creator) —
which is the active source of truth and the source of the Vercel deployment.

Development of VoiceAtelier should happen there, not here. The git history of
this repository preserves the earlier monorepo layout if you need to recover
anything; see the commit immediately preceding the cleanup commit.
